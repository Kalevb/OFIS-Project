# ศูนย์สืบสวนคดีฉ้อโกงออนไลน์ (Online Fraud Investigation Center - OFIC)

โครงงานวิชาการพัฒนาเว็บแอปพลิเคชัน (CSD3202) มหาวิทยาลัยราชภัฏสวนสุนันทา  
จัดทำโดย: 67122250043 นายวีรภัทร กรังพานิช  
อาจารย์ผู้สอน: ผศ.ดร.เสถียร จันทร์ปลา  

---

## 1. วัตถุประสงค์และขอบเขตของโครงงาน (Project Overview)
ระบบศูนย์กลางเพื่อสนับสนุนการแจ้งเหตุ ตรวจสอบ ติดตาม และวิเคราะห์ความเชื่อมโยงของคดีฉ้อโกงออนไลน์ (แก๊ง Call Center, หลอกลงทุน, หลอกซื้อขายสินค้า) 
ช่วยให้ผู้เสียหายแจ้งความและติดตามคดีได้สะดวกรวดเร็วแบบเรียลไทม์ และช่วยให้เจ้าหน้าที่สืบสวนตรวจจับความเชื่อมโยงของบัญชีม้า เบอร์โทรศัพท์ และเว็บไซต์หลอกลวงข้ามคดีได้อย่างเป็นระบบ

---

## 2. เทคโนโลยีที่ใช้ (Tech Stack)
- **Frontend**: React 19 + JavaScript (ES Modules, JSX) พัฒนาด้วย Vite
- **Routing**: React Router DOM (v7)
- **Database**: Firebase Realtime Database
- **Authentication**: Firebase Authentication (Email/Password) พร้อมระบบ Quick Demo Switcher
- **File Storage**: Firebase Storage (จัดเก็บหลักฐานภาพและ PDF)
- **Charts**: Chart.js + `react-chartjs-2`
- **Design System & Styling**: Custom CSS Tokens (สีหลัก `#1E3A8A`, สีรอง `#2563EB`, พื้นหลัง `#F8FAFC`), ฟอนต์ Kanit, Bootstrap Icons

## 3. หน้าจอและเส้นทางระบบ (Pages & Routes)

| รหัสหน้าจอ | เส้นทาง (Path) | บทบาทที่เข้าถึงได้ | คำอธิบายหน้าที่ |
|---|---|---|---|
| P01 | `/` | สาธารณะ (Public) | หน้าหลัก (Landing Page) ตรงตาม Wireframe Home.png 100% |
| P02 | `/login` | สาธารณะ | เข้าสู่ระบบ (มีแท็บสลับผู้เสียหาย / เจ้าหน้าที่ และปุ่ม Quick Test) |
| P03 | `/register` | สาธารณะ | สมัครสมาชิกผู้เสียหาย (กรอกบัตรประชาชนและข้อมูลติดต่อ) |
| P04 | `/victim/dashboard` | ผู้เสียหาย (Victim) | แดชบอร์ดภาพรวมคดีของผู้เสียหาย สถิติ และสถานะคดี |
| P05 | `/victim/submit-case` | ผู้เสียหาย | ฟอร์มแจ้งเหตุ 5 ขั้นตอน (Stepper Wizard) พร้อมแนบหลักฐาน |
| P06 | `/victim/track-status` | ผู้เสียหาย | ติดตามสถานะคดี ค้นหาด้วยรหัสคดี และความคืบหน้าแบบ Accordion |
| P07 | `/victim/profile` | ผู้เสียหาย / เจ้าหน้าที่ | โปรไฟล์และข้อมูลส่วนตัวของผู้ใช้งาน |
| P08 | `/officer/dashboard` | เจ้าหน้าที่ / แอดมิน | แดชบอร์ดสถิติ กราฟแนวโน้ม กราฟประเภทคดี และตารางจัดการคดี |
| P09 | `/officer/victims` | เจ้าหน้าที่ / แอดมิน | รายชื่อผู้เสียหายทั้งหมดในระบบ |
| P10 | `/officer/duplicates` | เจ้าหน้าที่ / แอดมิน | ระบบตรวจจับรายการซ้ำ (เบอร์โทร, เลขบัญชีม้า, เว็บไซต์) |
| P11 | `/officer/reports` | เจ้าหน้าที่ / แอดมิน | สร้างและส่งออกรายงานสรุปคดี (ดาวน์โหลดเป็นไฟล์ CSV) |
| P12 | `/officer/settings` | เจ้าหน้าที่ / แอดมิน | ตั้งค่าระดับความไวการตรวจจับข้อมูลซ้ำและการแจ้งเตือน |
| P13 | `/officer/users` | แอดมิน (Admin Only) | จัดการบัญชีผู้ใช้ สลับบทบาท และเปิด/ปิดการใช้งาน |
| P14 | `/cases/:caseId` | ผู้ใช้ที่เข้าสู่ระบบ | หน้ารายละเอียดคดีฉ้อโกงแบบเต็ม |
| P15 | `/cases/:caseId/evidence/:evidenceId` | ผู้ใช้ที่เข้าสู่ระบบ | รายละเอียดหลักฐาน ภาพพรีวิว และการยืนยัน/ปฏิเสธหลักฐาน |
| P16 | `/cases/:caseId/timeline` | ผู้ใช้ที่เข้าสู่ระบบ | ไทม์ไลน์บันทึกประวัติความเคลื่อนไหวคดี |

## 5. การเชื่อมต่อฐานข้อมูล Firebase (Cloud Firebase Integration)
ระบบเชื่อมต่อโดยตรงกับโปรเจกต์ **Firebase Realtime Database** และ **Firestore** (`ofis-project-230f8`) บน Cloud แบบ Real-time:
- ไม่จำเป็นต้องมีโฟลเดอร์ `database/` ในเครื่อง สามารถดาวน์โหลดโปรเจกต์และรัน `npm install && npm run dev` ได้ทันที
- ข้อมูลคดี (Cases), ไทม์ไลน์ (Timeline), ผู้ใช้งาน (Users) และสถิติจะถูกซิงค์กับฐานข้อมูล Firebase อัตโนมัติ
